VideoVault 本地下載站
連不到本地程式。請用 start.bat（或 python server.py）開啟本頁，而不是直接點兩下 HTML 檔。
尚未連結 GitHub 儲存庫。請點「設定」，貼上管理網站產生的設定碼。
沒有 GitHub Token：可以下載，但無法自動把影片標記為「已下載」。

下載來源

選擇器不會寫也沒關係，擴充功能會自己找網頁上的網址輸入框。填錯的話只是不會自動填入，不影響其他功能。

成功率來自你按「完成」或「換下一個來源」的紀錄，以及 yt-dlp 的下載結果。
關閉自動排序時，依你用 ↑↓ 排的順序。下載時若第一個來源失敗，可在下載卡片按「換下一個來源」。
